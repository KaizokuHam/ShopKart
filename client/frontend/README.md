# ShopKart frontend

The React storefront lives here. Use the [root README](../../README.md) for installation, environment configuration, MongoDB/Razorpay setup, and troubleshooting.

From the repository root:

```sh
npm ci
npm run setup
npm run dev
```

For frontend-only work from this directory:

```sh
npm ci
npm run dev
npm run lint
npm test
npm run build
npm run preview
```

Copy `.env.example` to `.env` to override the public API origin. The backend is required for catalogue data, authentication, and shopping features. `dist` is generated by `build` and should not be committed. Vite preview is for checking the static build, not a production web server.

UI foundations: React Router, Tailwind CSS, custom CSS variables, Lenis, Cormorant Garamond and Manrope. Reduced-motion preferences disable smooth scrolling and reduce visual motion. `src/components/ErrorBoundary.jsx` provides a recovery screen for unexpected rendering failures.
